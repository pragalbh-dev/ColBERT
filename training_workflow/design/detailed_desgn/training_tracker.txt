# TRAINING TRACKER

## Purpose
Monitor and log training progress, metrics, and artifacts.

## Responsibilities
1. Track metrics (loss, accuracy, custom metrics)
2. Save checkpoints at specified intervals
3. Log metrics to TensorBoard
4. Create and manage all log files and directories
5. Save final model artifacts
6. Maintain consistent directory structure for job outputs
7. Track checkpoint evaluations and visualize progression

## Responsibility Clarification
The Training Tracker is the ONLY component responsible for:
- Creating and writing to log files
- Saving metrics to disk
- Managing TensorBoard logging
- Saving model checkpoints during training
- Evaluating checkpoints and tracking their performance

The Training Job delegates ALL logging and tracking responsibilities to the Training Tracker.

## Checkpoint Evaluation Tracking

The Training Tracker provides functionality to:
1. Evaluate model checkpoints during or after training
2. Track evaluation metrics for each checkpoint
3. Visualize progression of metrics across checkpoints
4. Compare checkpoint performance

### Implementation Details:

1. **Checkpoint Evaluation Storage**:
   - Create a dedicated directory for checkpoint evaluations
   - Store evaluation results in JSON format for each checkpoint
   - Link checkpoints to their evaluation metrics in metadata

2. **Evaluation Methods**:
   - `log_checkpoint_evaluation(epoch, metrics)`: Log evaluation results for a checkpoint
   - `evaluate_checkpoint(epoch, eval_function)`: Evaluate a specific checkpoint using a provided function
   - `get_checkpoint_evaluations()`: Retrieve all checkpoint evaluations

3. **Visualization**:
   - Add checkpoint markers to training metric plots
   - Create dedicated visualizations showing metric progression across checkpoints
   - Provide comparison tools for different checkpoints

4. **TensorBoard Integration**:
   - Add checkpoint evaluation metrics to TensorBoard
   - Create custom scalar plots with checkpoint annotations
   - Enable side-by-side comparison of training and evaluation metrics

## Interface

from typing import Dict, List, Any, Callable, Optional
import os
import time
import json
from pathlib import Path
import functools
import torch
import matplotlib.pyplot as plt
from experiment_module.tracking import BaseTracker
from experiment_module.artifacts import ArtifactManager

class TrainingTracker(BaseTracker):
    def __init__(self, 
                 experiment_name: str, 
                 job_id: str, 
                 log_dir: Optional[str] = None,
                 artifact_manager: Optional[ArtifactManager] = None,
                 checkpoint_interval: int = 1):
        """
        Initialize training tracker
        
        Args:
            experiment_name: Name of the experiment
            job_id: ID of the training job
            log_dir: Directory for logs (default: experiments/{experiment_name}/{job_id})
            artifact_manager: Optional artifact manager instance
            checkpoint_interval: How often to save checkpoints (in epochs)
        """
        # Initialize base tracker
        super().__init__(experiment_name, job_id, log_dir, artifact_manager)
        
        # Create additional directories specific to training
        self.checkpoint_dir = self.log_dir / "checkpoints"
        self.model_dir = self.log_dir / "models"
        self.checkpoint_eval_dir = self.log_dir / "checkpoint_evaluations"
        
        os.makedirs(self.checkpoint_dir, exist_ok=True)
        os.makedirs(self.model_dir, exist_ok=True)
        os.makedirs(self.checkpoint_eval_dir, exist_ok=True)
        
        # Training-specific settings
        self.checkpoint_interval = checkpoint_interval
        self.current_epoch = 0
        self.best_metric = None
        self.best_metric_value = None
        self.best_model_path = None
        
        # Track checkpoint evaluations
        self.checkpoint_evaluations = {}
        
        print(f"Training tracker initialized for experiment '{experiment_name}', job '{job_id}'")
        print(f"Logs will be saved to {self.log_dir}")
    
    def log_epoch(self, 
                 epoch: int, 
                 metrics: Dict[str, float],
                 commit: bool = True) -> None:
        """
        Log metrics for an epoch
        
        Args:
            epoch: Epoch number
            metrics: Dictionary of metric names and values
            commit: Whether to immediately write to disk
        """
        self.current_epoch = epoch
        
        # Use base class method to log metrics
        self.log_metrics(metrics, step=epoch, commit=commit)
        
        # Update best metric if specified
        if self.best_metric is not None and self.best_metric in metrics:
            current_value = metrics[self.best_metric]
            if self.best_metric_value is None or current_value > self.best_metric_value:
                self.best_metric_value = current_value
                print(f"New best {self.best_metric}: {current_value} (epoch {epoch})")
    
    def save_checkpoint(self, 
                       model: Any, 
                       optimizer: Any, 
                       epoch: int, 
                       additional_data: Optional[Dict[str, Any]] = None) -> str:
        """
        Save model checkpoint
        
        Args:
            model: Model to save
            optimizer: Optimizer state
            epoch: Current epoch
            additional_data: Any additional data to save
            
        Returns:
            Path to saved checkpoint
        """
        # Create checkpoint dictionary
        checkpoint = {
            'epoch': epoch,
            'model_state_dict': model.state_dict(),
            'optimizer_state_dict': optimizer.state_dict(),
        }
        
        # Add any additional data
        if additional_data:
            checkpoint.update(additional_data)
        
        # Use ArtifactManager to save the checkpoint
        artifact_path = self.artifact_manager.save_checkpoint(
            checkpoint, 
            self.experiment_name, 
            self.job_id, 
            epoch
        )
        
        # Also save a local copy in the job directory for convenience
        local_path = self.checkpoint_dir / f"checkpoint_epoch_{epoch}.pt"
        os.makedirs(os.path.dirname(str(local_path)), exist_ok=True)
        torch.save(checkpoint, local_path)
        
        print(f"Saved checkpoint for epoch {epoch} to {local_path}")
        return str(local_path)
    
    def save_model(self, 
                  model: Any, 
                  name: str = "model.pt", 
                  metadata: Optional[Dict[str, Any]] = None) -> str:
        """
        Save final model
        
        Args:
            model: Model to save
            name: Model filename
            metadata: Optional metadata to save with the model
            
        Returns:
            Path to saved model
        """
        # Use ArtifactManager to save the model
        artifact_path = self.artifact_manager.save_model(
            model,
            self.experiment_name,
            self.job_id,
            name,
            metadata
        )
        
        # Also save a local copy in the job directory for convenience
        model_path = self.model_dir / name
        os.makedirs(os.path.dirname(str(model_path)), exist_ok=True)
        
        # Save model state dict
        torch.save(model.state_dict(), model_path)
        
        # Save metadata if provided
        if metadata:
            metadata_path = model_path.with_suffix('.json')
            with open(metadata_path, 'w') as f:
                json.dump(metadata, f, indent=2)
        
        print(f"Saved model to {model_path}")
        return str(model_path)
    
    def set_best_metric(self, metric_name: str, mode: str = 'max') -> None:
        """
        Set a metric to track for best model selection
        
        Args:
            metric_name: Name of the metric to track
            mode: 'max' or 'min' depending on whether higher or lower is better
        """
        self.best_metric = metric_name
        self.best_metric_mode = mode
        self.best_metric_value = None
        print(f"Tracking best model based on {metric_name} ({mode})")
    
    def save_best_model(self, 
                       model: Any, 
                       metric_value: float, 
                       epoch: int) -> Optional[str]:
        """
        Save model if it's the best so far according to the tracked metric
        
        Args:
            model: Model to save
            metric_value: Current value of the tracked metric
            epoch: Current epoch
            
        Returns:
            Path to saved model if it was the best, None otherwise
        """
        if self.best_metric is None:
            print("No best metric set, skipping best model saving")
            return None
        
        is_best = False
        if self.best_metric_value is None:
            is_best = True
        elif self.best_metric_mode == 'max' and metric_value > self.best_metric_value:
            is_best = True
        elif self.best_metric_mode == 'min' and metric_value < self.best_metric_value:
            is_best = True
        
        if is_best:
            self.best_metric_value = metric_value
            model_path = self.save_model(
                model, 
                f"best_model_{self.best_metric}.pt",
                metadata={
                    'metric': self.best_metric,
                    'value': metric_value,
                    'epoch': epoch,
                    'timestamp': time.time()
                }
            )
            self.best_model_path = model_path
            print(f"New best model saved with {self.best_metric} = {metric_value}")
            return model_path
        
        return None
    
    def log_checkpoint_evaluation(self, 
                                 epoch: int, 
                                 metrics: Dict[str, Any]) -> None:
        """
        Log evaluation results for a checkpoint
        
        Args:
            epoch: Epoch number of the checkpoint
            metrics: Dictionary of evaluation metrics
        """
        # Store evaluation results
        self.checkpoint_evaluations[epoch] = metrics
        
        # Save to disk
        eval_file = self.checkpoint_eval_dir / f"eval_epoch_{epoch}.json"
        with open(eval_file, "w") as f:
            json.dump(metrics, f, indent=2)
        
        # Log to TensorBoard with special tag
        for metric_name, value in metrics.items():
            if isinstance(value, (int, float)):
                self.writer.add_scalar(f"checkpoint_eval/{metric_name}", value, epoch)
        
        # Add checkpoint marker to training metrics
        for metric_name, value in metrics.items():
            if isinstance(value, (int, float)) and metric_name in self.metrics:
                # Add a vertical line or marker in TensorBoard
                # This requires custom scalar support in TensorBoard
                self.writer.add_scalar(f"checkpoint_markers/{metric_name}", value, epoch)
        
        print(f"Logged evaluation for checkpoint at epoch {epoch}")
    
    def evaluate_checkpoint(self, 
                           epoch: int, 
                           eval_function: Callable[[Any], Dict[str, Any]],
                           model_class: Optional[Any] = None) -> Dict[str, Any]:
        """
        Evaluate a specific checkpoint using provided function
        
        Args:
            epoch: Epoch number of the checkpoint to evaluate
            eval_function: Function that takes a model and returns evaluation metrics
            model_class: Optional model class for loading the checkpoint
            
        Returns:
            Dictionary of evaluation metrics
        """
        # Find checkpoint file
        checkpoint_path = self.checkpoint_dir / f"checkpoint_epoch_{epoch}.pt"
        if not checkpoint_path.exists():
            raise FileNotFoundError(f"Checkpoint for epoch {epoch} not found")
        
        # Load checkpoint
        checkpoint = torch.load(checkpoint_path)
        
        # Load model
        if model_class is not None:
            model = model_class()
            model.load_state_dict(checkpoint['model_state_dict'])
        else:
            # Assume checkpoint contains the model directly
            model = checkpoint.get('model', checkpoint.get('model_state_dict'))
        
        # Evaluate model
        metrics = eval_function(model)
        
        # Log evaluation results
        self.log_checkpoint_evaluation(epoch, metrics)
        
        return metrics
    
    def get_checkpoint_evaluations(self) -> Dict[int, Dict[str, Any]]:
        """
        Get all checkpoint evaluations
        
        Returns:
            Dictionary mapping epoch numbers to evaluation results
        """
        return self.checkpoint_evaluations
    
    def plot_checkpoint_evaluations(self, 
                                   metric_name: str, 
                                   include_training_metrics: bool = True,
                                   save_path: Optional[str] = None) -> None:
        """
        Plot evaluation results for a specific metric across checkpoints
        
        Args:
            metric_name: Name of the metric to plot
            include_training_metrics: Whether to include training metrics in the plot
            save_path: Optional path to save the plot
        """
        import matplotlib.pyplot as plt
        
        if not self.checkpoint_evaluations:
            print("No checkpoint evaluations available")
            return
        
        # Get checkpoint evaluation data
        epochs = sorted(self.checkpoint_evaluations.keys())
        values = [self.checkpoint_evaluations[epoch].get(metric_name, None) for epoch in epochs]
        
        # Filter out None values
        valid_data = [(e, v) for e, v in zip(epochs, values) if v is not None]
        if not valid_data:
            print(f"No data available for metric '{metric_name}'")
            return
        
        valid_epochs, valid_values = zip(*valid_data)
        
        plt.figure(figsize=(12, 6))
        
        # Plot checkpoint evaluations
        plt.plot(valid_epochs, valid_values, 'o-', linewidth=2, markersize=8, 
                label=f'Checkpoint {metric_name}')
        
        # Add training metrics if available and requested
        if include_training_metrics and metric_name in self.metrics:
            train_epochs = []
            train_values = []
            
            for entry in self.metrics[metric_name]:
                if entry["step"] is not None:
                    train_epochs.append(entry["step"])
                    train_values.append(entry["value"])
            
            if train_epochs:
                plt.plot(train_epochs, train_values, '.-', alpha=0.5, 
                        label=f'Training {metric_name}')
                
                # Add vertical lines at checkpoint epochs
                for epoch in valid_epochs:
                    plt.axvline(x=epoch, color='gray', linestyle='--', alpha=0.3)
        
        plt.xlabel('Epoch')
        plt.ylabel(metric_name)
        plt.title(f'Metric Progression: {metric_name}')
        plt.grid(True, alpha=0.3)
        plt.legend()
        
        # Save or show the plot
        if save_path:
            plt.savefig(save_path)
            # Also add to TensorBoard
            self.add_figure(f"checkpoint_eval/{metric_name}", plt.gcf())
        else:
            plt.show()
        
        plt.close()
    
    def compare_checkpoints(self, 
                           epochs: List[int], 
                           metrics: Optional[List[str]] = None,
                           save_path: Optional[str] = None) -> Dict[str, Any]:
        """
        Compare multiple checkpoints based on their evaluation metrics
        
        Args:
            epochs: List of epoch numbers to compare
            metrics: Optional list of metrics to compare (default: all metrics)
            save_path: Optional path to save the comparison plot
            
        Returns:
            Dictionary with comparison results
        """
        if not self.checkpoint_evaluations:
            print("No checkpoint evaluations available")
            return {}
        
        # Filter epochs that have evaluations
        valid_epochs = [e for e in epochs if e in self.checkpoint_evaluations]
        if not valid_epochs:
            print("No evaluations available for the specified epochs")
            return {}
        
        # Determine which metrics to compare
        if metrics is None:
            # Use all metrics that are present in all checkpoint evaluations
            all_metrics = set()
            for e in valid_epochs:
                all_metrics.update(self.checkpoint_evaluations[e].keys())
            
            # Filter for numeric metrics only
            metrics = [m for m in all_metrics if all(
                isinstance(self.checkpoint_evaluations[e].get(m), (int, float))
                for e in valid_epochs
            )]
        
        # Create comparison data
        comparison = {
            "epochs": valid_epochs,
            "metrics": {}
        }
        
        for metric in metrics:
            comparison["metrics"][metric] = {
                str(e): self.checkpoint_evaluations[e].get(metric)
                for e in valid_epochs
            }
        
        # Create comparison visualization
        if metrics and valid_epochs:
            self._create_checkpoint_comparison_chart(valid_epochs, metrics, save_path)
        
        return comparison
    
    def _create_checkpoint_comparison_chart(self, 
                                           epochs: List[int], 
                                           metrics: List[str],
                                           save_path: Optional[str] = None) -> None:
        """
        Create a chart comparing metrics across checkpoints
        
        Args:
            epochs: List of epoch numbers to compare
            metrics: List of metrics to compare
            save_path: Optional path to save the plot
        """
        import matplotlib.pyplot as plt
        import numpy as np
        
        # Set up the plot
        n_metrics = len(metrics)
        n_epochs = len(epochs)
        
        plt.figure(figsize=(max(12, n_epochs * 1.5), max(8, n_metrics * 0.8)))
        
        # Create a grouped bar chart
        width = 0.8 / n_epochs
        x = np.arange(n_metrics)
        
        for i, epoch in enumerate(epochs):
            values = [self.checkpoint_evaluations[epoch].get(m, 0) for m in metrics]
            plt.bar(x + i * width - 0.4 + width/2, values, width, label=f'Epoch {epoch}')
        
        plt.xlabel('Metrics')
        plt.ylabel('Values')
        plt.title('Checkpoint Comparison')
        plt.xticks(x, metrics, rotation=45, ha="right")
        plt.legend()
        plt.tight_layout()
        
        # Save or show the plot
        if save_path:
            plt.savefig(save_path)
            # Also add to TensorBoard
            self.add_figure("checkpoint_comparison", plt.gcf())
        else:
            plt.show()
        
        plt.close()
    
    def save_results(self, results: Dict[str, Any]) -> str:
        """
        Save final results to disk
        
        Args:
            results: Dictionary of results
            
        Returns:
            Path to saved results
        """
        results_path = self.log_dir / "results.json"
        
        # Add timestamp and duration
        results_with_meta = {
            **results,
            "timestamp": time.time(),
            "duration": time.time() - self.start_time
        }
        
        # Save to disk
        with open(results_path, "w") as f:
            json.dump(results_with_meta, f, indent=2)
            
        return str(results_path)
    
    def close(self) -> None:
        """Close tracker and release resources"""
        # Save final metrics
        self.flush()
        
        # Log total duration
        duration = time.time() - self.start_time
        with open(self.log_dir / "duration.txt", "w") as f:
            f.write(f"Total duration: {duration:.2f} seconds")
        
        # Update job metadata
        metadata = {
            "experiment_name": self.experiment_name,
            "job_id": self.job_id,
            "status": "completed",
            "start_time": self.start_time,
            "end_time": time.time(),
            "duration": duration,
            "best_metric": self.best_metric,
            "best_metric_value": self.best_metric_value,
            "best_model_path": self.best_model_path
        }
        
        with open(self.log_dir / "metadata.json", "w") as f:
            json.dump(metadata, f, indent=2)
        
        # Call parent close method
        super().close()
    
    # Decorator for training functions
    @staticmethod
    def track(experiment_name: str, job_id: str, log_dir: Optional[str] = None):
        """
        Decorator for tracking training functions
        
        Example:
            @TrainingTracker.track("experiment1", "job1")
            def train(model, dataloader, epochs, tracker=None):
                # Training code using tracker
        """
        def decorator(func: Callable):
            @functools.wraps(func)
            def wrapper(*args, **kwargs):
                with TrainingTracker(experiment_name, job_id, log_dir) as tracker:
                    # Add tracker to kwargs if not already present
                    if 'tracker' not in kwargs:
                        kwargs['tracker'] = tracker
                    return func(*args, **kwargs)
            return wrapper
        return decorator

3. As an explicit object passed to training functions


## Directory Structure
experiments/{experiment_name}/{job_id}/
├── logs/                      # TensorBoard event files
├── metrics/                   # JSON files with logged metrics
│   └── metrics.json           # All metrics in JSON format
├── models/                    # Saved model artifacts
│   ├── model.pt               # Final trained model
│   └── best_model_*.pt        # Best model based on tracked metric
├── checkpoints/               # Model checkpoints
│   └── checkpoint_epoch_*.pt  # Checkpoints at different epochs
├── checkpoint_evaluations/    # Evaluation results for checkpoints
│   └── eval_epoch_*.json      # Evaluation metrics for each checkpoint
├── hyperparameters.json       # Configuration used for training
├── results.json               # Final evaluation results
├── metadata.json              # Job metadata (status, timing, etc.)
└── duration.txt               # Training duration
